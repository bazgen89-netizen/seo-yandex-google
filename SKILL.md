# Аудит сайта под Яндекс

Программа `scripts/yaudit.py` обходит сайт с заголовком YandexBot, читает robots.txt так, как его читает
Яндекс, и пишет отчёт на русском: **Критично → Важно → Желательно → К сведению**, у каждой находки –
почему это важно для Яндекса, что сделать и примеры адресов.

## Запуск

```bash
# быстрая проверка: до 300 страниц
python3 scripts/yaudit.py https://example.ru -o yandex-audit.md

# полная: весь сайт, данные Вебмастера, орфография, YML-фид
YANDEX_WEBMASTER_TOKEN=... python3 scripts/yaudit.py https://example.ru --max-pages 2000 \
    --webmaster --speller --yml https://example.ru/market.yml -o yandex-audit.md

# для разбора программой
python3 scripts/yaudit.py https://example.ru --format json -o yandex-audit.json
```

Флаги: `--max-pages` (300), `--workers` (4), `--delay` (пауза, с), `--include` / `--exclude`
(регулярные выражения по пути), `--webmaster`, `--speller`, `--speller-pages` (150), `--yml`,
`--format md|json`, `-o`, `-q`.

Адреса из карты сайта обходятся первыми, затем ссылки со страниц. Закрытое в robots.txt для Яндекса
не обходится, но попадает в отчёт, если стоит в карте сайта.

## Как работать агенту

1. **Адрес сайта.** Нет в запросе – найди в проекте (конфиг деплоя, `.env`, README) и только потом спроси.
2. **Токен Вебмастера.** Проверь `YANDEX_WEBMASTER_TOKEN`. Есть – запускай с `--webmaster`: без него
   не видно, что Яндекс уже исключил и почему. Нет – скажи владельцу, как получить (README, раздел
   «Токен Вебмастера»), и запусти без него.
3. **Объём.** Первый запуск – `--max-pages 300`; если в карте сайта больше страниц и отчёт полезен –
   повтори на весь сайт. Для магазина добавь `--yml` с адресом фида, для сайта с текстами – `--speller`.
4. **Чтение отчёта.** Начинай с «Критично» и с блока «Яндекс Вебмастер»: это то, что уже стоит позиций.
   Находки с пометкой «Вебмастер:» – мнение самого Яндекса, они весомее эвристик программы.
5. **Проверь глазами перед правкой.** Эвристики ошибаются:
   - «Мало текста» на карточке товара с ценой и фото – не всегда проблема;
   - Спеллер не знает терминов и транслитерации, его находки – список на проверку, не на автозамену;
   - «Робот получает другой ответ» и «Страница не открывается» сначала перезапусти: бывают сетевые сбои
     у тебя, а не у сайта.
6. **Исправление.** Предлагай правки по одной группе (robots.txt, шаблон title, редиректы зеркал…),
   после правки – повторный запуск той же командой и сравнение счётчиков.
7. **Отчитываясь,** называй находку, число страниц, пример адреса и что сделано. Не пересказывай весь отчёт.

## Что проверяется

| Блок | Проверки |
|---|---|
| robots.txt | доступность, закрыт ли сайт для Яндекса, группа `User-agent: Yandex` без запретов из `*`, закрытые CSS/JS/картинки, `Sitemap`, `Clean-param`, устаревшие `Host` и `Crawl-delay`, размер больше 500 КБ |
| Зеркала | http → https и www ↔ без www: 301 на главное зеркало, временные редиректы, редирект с главной |
| Ответы | мягкая 404, 5xx на несуществующих адресах, ошибки 4xx/5xx, цепочки редиректов, 302 внутри сайта, YandexBot и браузер получают одно и то же, средний ответ сервера |
| Карта сайта | наличие, XML, индексы, 50 000 адресов / 50 МБ, чужой домен, lastmod, адреса под Disallow, noindex и неканонические страницы в карте, страницы без внутренних ссылок |
| Страницы | title (нет, длина, дубли), description (нет, длина, дубли), H1, canonical (нет, несколько, относительный), noindex и `<meta name="yandex">`, viewport, lang, мало текста, одинаковый текст, смешанный контент, alt у картинок, тяжёлый HTML, внутренние nofollow, ссылки на редиректы, битые ссылки |
| Разметка | ошибки JSON-LD, Product без цены, Organization / LocalBusiness на главной, Open Graph |
| Сервисы Яндекса | счётчик Метрики на всех страницах и один ли он, `yandex-verification`, фавикон 120×120 или SVG, дубли с utm и Clean-param, адрес со слешем и без |
| Вебмастер (`--webmaster`) | ИКС, страниц в поиске и исключено, диагностика с переводом кодов, ошибки карт сайта, битые внутренние ссылки и их шаблоны, причины недавних исключений (малоценная, неканоническая, дубль), популярные запросы за 30 дней |
| Спеллер (`--speller`) | опечатки в тексте страниц, без имён собственных и латиницы |
| YML (`--yml`) | доступность и XML, обязательные поля товаров (url, price, currencyId, categoryId, picture, name), цена больше нуля, ссылки на свой домен |

## Ограничения

- Читает HTML как его отдаёт сервер, без выполнения JavaScript. Сайт, у которого текст появляется
  только после скриптов, Яндекс видит лучше, чем эта программа, но хуже, чем браузер. Если страницы
  выглядят пустыми, проверь страницу в Вебмастере: Инструменты → Проверка ответа сервера.
- Скорость загрузки в браузере (LCP, CLS) не меряет – только время ответа сервера.
- Данные Вебмастера – выборки API (до 100 событий и ссылок); полные списки – в самом Вебмастере.
