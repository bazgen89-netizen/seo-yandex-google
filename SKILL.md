# SEO-аудит сайта для Яндекса и Google

Программа `scripts/seo_audit.py` обходит сайт как робот Яндекса (при `--engine google` – как Googlebot), читает
robots.txt по правилам каждого робота, сверяет ответы YandexBot и Googlebot с браузером, проверяет 87 параметров и пишет отчёт на русском: **Критично → Важно → Желательно → К сведению**. У каждой
находки – почему это важно, что сделать и примеры адресов. Общее для обоих поисковиков идёт без пометки,
особенности – с пометкой «Яндекс ·» или «Google ·». Полный список проверок – в README.

## Запуск

```bash
python3 scripts/seo_audit.py https://example.ru -o audit.md                     # оба поисковика, до 300 страниц
python3 scripts/seo_audit.py https://example.ru --engine yandex -o audit.md     # только Яндекс
python3 scripts/seo_audit.py https://example.ru --engine google -o audit.md     # только Google
python3 scripts/seo_audit.py https://example.ru --all --max-pages 2000 -o audit.md   # с Вебмастером, Search Console, PageSpeed, Спеллером
python3 scripts/seo_audit.py https://example.ru --format json -o audit.json     # для разбора программой
```

Флаги: `--engine both|yandex|google`, `--max-pages` (300), `--workers` (4), `--delay`, `--include` / `--exclude`
(регулярные выражения по пути), `--webmaster`, `--gsc`, `--gsc-inspect` (30), `--psi`, `--psi-pages` (4),
`--speller`, `--all`, `--yml URL`, `--format md|json`, `-o`, `-q`.

## Как работать агенту

1. **Адрес сайта.** Нет в запросе – найди в проекте (конфиг деплоя, `.env`, README), только потом спроси.
2. **Поисковик.** «Под Яндекс» – `--engine yandex`, «под Google» – `--engine google`, иначе оба.
3. **Ключи.** Проверь переменные `YANDEX_WEBMASTER_TOKEN`, `GSC_KEY` / `GSC_ACCESS_TOKEN`, `PAGESPEED_API_KEY`.
   Есть – добавь `--webmaster`, `--gsc`, `--psi` (или `--all`): без них не видно, что поисковики уже исключили
   и почему. Нет – запусти без них и скажи владельцу, где взять (README, раздел «Ключи»). PageSpeed без ключа
   работает, но быстро упирается в лимит.
4. **Объём.** Первый запуск – до 300 страниц; если в карте сайта больше и отчёт полезен – весь сайт.
   Магазину добавь `--yml` с адресом фида, сайту с текстами – `--speller`.
5. **Чтение отчёта.** Начинай с «Критично» и с блоков Вебмастера и Search Console: находки с пометкой
   «Вебмастер:» и «Search Console:» – мнение самих поисковиков, они весомее эвристик программы.
6. **Проверь глазами перед правкой.** Эвристики ошибаются:
   - «Мало текста» на карточке товара с ценой и фото – не всегда проблема;
   - Спеллер не знает терминов и транслитерации – это список на проверку, не на автозамену;
   - «Робот получает другой ответ» и «Страница не открывается» сначала перезапусти: сетевые сбои бывают у тебя,
     а не у сайта; на сайтах с защитой от ботов несуществующие адреса роботам могут отвечать 503 намеренно.
7. **Исправление.** Предлагай правки группами (robots.txt, шаблон title, редиректы зеркал, разметка товара…),
   после правки – тот же запуск ещё раз и сравнение счётчиков.
8. **Отчитываясь,** называй находку, число страниц, пример адреса и что сделано. Не пересказывай весь отчёт.

## Ограничения

- JavaScript не выполняется: программа видит HTML от сервера. Если страницы выглядят пустыми – проверь
  «Проверку URL» в Search Console и «Проверку ответа сервера» в Вебмастере.
- Скорость меряет Google PageSpeed, не свой браузер.
- Данные Вебмастера и Search Console – выборки API (до 100 событий, до `--gsc-inspect` страниц на индексацию).
