# yandex-seo-audit – аудит сайта под Яндекс

Навык для Claude Code и самостоятельная программа на Python. Обходит сайт так, как его видит робот
Яндекса, и пишет отчёт на русском: что мешает сайту в Яндексе, почему и как исправить.

Большинство SEO-аудиторов написаны под Google: они не знают про `Clean-param`, группу
`User-agent: Yandex`, склейку зеркал, Вебмастер, ИКС и YML-фиды, а русский текст оценивают
английскими формулами. Этот – только про Яндекс.

- robots.txt **по правилам Яндекса**: своя группа Yandex, `Clean-param`, устаревшие `Host` и `Crawl-delay`;
- главное зеркало: http/https, www/без www, 301 или 302;
- карта сайта, мягкие 404, дубли с метками и со слешем, битые ссылки, редиректы;
- title, description, H1, canonical, noindex, разметка Product и Organization, Open Graph, Метрика, фавикон;
- **Яндекс Вебмастер**: ИКС, диагностика с переводом кодов, почему страницы исключены, битые ссылки, запросы;
- **Яндекс Спеллер**: опечатки в текстах;
- **YML-фид** для Яндекс Маркета и «Товаров».

Ставить ничего не нужно: Python 3.8+ и стандартная библиотека.

## Установка как навыка Claude Code

```bash
git clone https://github.com/bazgen89-netizen/yandex-seo-audit-skill ~/.claude/skills/yandex-seo-audit
```

Для одного проекта – в папку проекта: `.claude/skills/yandex-seo-audit`. После этого достаточно
попросить: «проверь сайт example.ru под Яндекс» или вызвать `/yandex-seo-audit`.

## Запуск без Claude

```bash
python3 scripts/yaudit.py https://example.ru -o yandex-audit.md
```

Полная проверка:

```bash
export YANDEX_WEBMASTER_TOKEN=ваш_токен
python3 scripts/yaudit.py https://example.ru --max-pages 2000 --webmaster --speller \
    --yml https://example.ru/market.yml -o yandex-audit.md
```

| Флаг | Что делает | По умолчанию |
|---|---|---|
| `--max-pages N` | сколько страниц обойти | 300 |
| `--workers N` | одновременных запросов | 4 |
| `--delay S` | пауза между пачками запросов, секунд | 0 |
| `--include RE` / `--exclude RE` | обходить только / не обходить пути по регулярному выражению | |
| `--webmaster` | данные Яндекс Вебмастера (нужен токен) | выкл. |
| `--speller` | орфография Яндекс Спеллером | выкл. |
| `--speller-pages N` | сколько страниц проверять Спеллером | 150 |
| `--yml URL` | проверить YML-фид | |
| `--format md\|json` | отчёт для человека или для программы | md |
| `-o FILE` | куда записать отчёт | на экран |

Сайт обходится с заголовком `YandexBot/3.0`. Если на сайте есть защита от ботов, она увидит обычный
поток запросов от робота: по умолчанию 4 одновременно. Для слабого хостинга добавьте `--workers 2 --delay 0.5`.

## Токен Вебмастера

Без токена программа проверяет сайт снаружи. С токеном – добавляет то, что Яндекс уже знает о сайте:
какие страницы исключил и почему, какие проблемы видит в диагностике, где битые ссылки.

1. Создайте приложение на [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new):
   платформа «Веб-сервисы», Redirect URI – `https://oauth.yandex.ru/verification_code`,
   доступ – «Яндекс.Вебмастер: получение информации о сайтах и статистики» (`webmaster:hostinfo`).
2. Откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`,
   войдите тем аккаунтом, в котором сайт добавлен в Вебмастер, и скопируйте токен.
3. `export YANDEX_WEBMASTER_TOKEN=токен` (действует год).

Токен никуда, кроме `api.webmaster.yandex.net`, не отправляется. Не храните его в репозитории.

## Что в отчёте

Находки сгруппированы по важности: **Критично**, **Важно**, **Желательно**, **К сведению**. У каждой –
почему это важно именно для Яндекса (с кодом из Вебмастера, если он есть), что сделать и до восьми
примеров адресов. Отдельные блоки – данные Вебмастера и «В порядке» (что проверено и без замечаний).

Пример находки:

```
### Адреса с метками utm – дубли страниц

**Почему:** Страница с ?utm_source=… отвечает 200 без canonical на чистый адрес, а Clean-param для utm нет.
Яндекс может проиндексировать копии с метками из рекламы и рассылок.

**Что сделать:** Добавьте canonical на чистый адрес и Clean-param: utm_source&utm_medium&utm_campaign в robots.txt.

- https://example.ru/catalog/?utm_source=yaudit
```

## Что не проверяется

- JavaScript не выполняется: программа видит HTML, который отдаёт сервер.
- Скорость в браузере (LCP, CLS) не меряется, только время ответа сервера. Для неё есть Lighthouse и
  [SEOmator](https://github.com/seo-skills/seo-audit-skill) – он подробнее проверяет техническую часть под Google,
  а этот навык дополняет его тем, что важно для Яндекса.
- Данные Вебмастера – выборки API (до 100 событий и ссылок), полные списки – в кабинете.

## Проверка самой программы

```bash
python3 -m unittest discover -s tests -v
```

Тест поднимает маленький сайт с заранее известными ошибками и проверяет, что программа их находит и
не поднимает ложных тревог.
