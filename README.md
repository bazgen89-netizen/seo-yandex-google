# seo-yandex-google – SEO-аудит сайта для Яндекса и Google

Навык для Claude Code и самостоятельная программа на Python. Обходит сайт как робот Яндекса, читает robots.txt
по правилам роботов Яндекса и Google, сверяет их ответы с браузером и пишет отчёт на русском: что мешает сайту в поиске, почему и как исправить.

Большинство SEO-аудиторов сделаны под Google: они не знают про `Clean-param`, группу `User-agent: Yandex`,
склейку зеркал, Вебмастер, ИКС и YML-фиды, а русский текст оценивают английскими формулами. Этот проверяет
сайт сразу под оба поисковика: общее – одним списком, особенности Яндекса и Google – с пометкой.

**87 проверок самого сайта и 69 параметров из данных Яндекс Вебмастера, Google Search Console и PageSpeed –
всего 156** (полный список ниже).

Ставить ничего не нужно: Python 3.10+ и стандартная библиотека.

## Запуск без Claude

```bash
python3 scripts/seo_audit.py https://example.ru -o audit.md                    # оба поисковика
python3 scripts/seo_audit.py https://example.ru --engine yandex -o audit.md    # только Яндекс
python3 scripts/seo_audit.py https://example.ru --engine google -o audit.md    # только Google
python3 scripts/seo_audit.py https://example.ru --all --max-pages 2000 \
    --yml https://example.ru/market.yml -o audit.md                            # всё сразу
```

## Ключи (по желанию)

Без ключей программа проверяет сайт снаружи – это все 87 проверок. Ключи добавляют то, что поисковики уже
знают о сайте. Ключи никуда, кроме API Яндекса и Google, не отправляются; не храните их в репозитории.

**Яндекс Вебмастер** – переменная `YANDEX_WEBMASTER_TOKEN`:
1. [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new): платформа «Веб-сервисы», Redirect URI
   `https://oauth.yandex.ru/verification_code`, доступ «Яндекс.Вебмастер: получение информации о сайтах и статистики».
2. Откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID` тем аккаунтом,
   где сайт добавлен в Вебмастер, и скопируйте токен (действует год).

**Google Search Console** – переменная `GSC_KEY` (путь к JSON-ключу сервисного аккаунта) или `GSC_ACCESS_TOKEN`:
1. [console.cloud.google.com](https://console.cloud.google.com/): включите Google Search Console API, создайте
   сервисный аккаунт (IAM → Service Accounts) и скачайте ключ JSON.
2. В Search Console → Настройки → Пользователи и разрешения добавьте почту сервисного аккаунта.
3. `export GSC_KEY=/путь/к/ключу.json` (для подписи нужен `openssl`, он есть в Linux и macOS).

**Google PageSpeed** – переменная `PAGESPEED_API_KEY` (без неё Google быстро упирается в лимит): Google Cloud →
APIs & Services → включить PageSpeed Insights API → Credentials → API key. Бесплатно, 25 000 запросов в сутки.

## Отчёт

Находки сгруппированы по важности: **Критично**, **Важно**, **Желательно**, **К сведению**. У каждой – почему
это важно (с кодом из Вебмастера или Search Console, если он есть), что сделать и до восьми примеров адресов.
Особенности одного поисковика помечены «Яндекс ·» или «Google ·». Отдельные блоки – Яндекс Вебмастер,
Search Console, скорость и «В порядке».

### 9. Яндекс Вебмастер (`--webmaster`, 46 параметров)

- ИКС, сколько страниц в поиске и сколько исключено;
- **32 вида проблем из диагностики Вебмастера** с переводом на понятный русский и советом: ошибки DNS и сервера,
  закрытие в robots.txt, угрозы безопасности, медленный ответ, 4xx и 5xx на важных страницах, нет карты сайта

  выключен, страницы не адаптированы для телефона, сайт не связан с Яндекс Бизнесом, не задан регион, лишние
  параметры в адресах, много поддоменов в поиске и другие;
- **8 причин, почему страницы выпали из поиска:** малоценная, неканоническая, дубль, ошибка HTTP, редирект,
  noindex, robots.txt, склейка по Clean-param;
- битые внутренние ссылки по данным Яндекса с шаблонами адресов (например, `…/feed/`);
- ошибки в картах сайта;
- популярные запросы за 30 дней: показы, клики, позиция.

### 10. Google Search Console (`--gsc`, 19 параметров)

- показы, клики и средняя позиция за 30 дней, популярные запросы;
- карты сайта: ошибки и отправлена ли карта вообще;
- **проверка индексации выбранных страниц** (URL Inspection) и **11 причин, почему страница не в индексе:**
  просканирована, но не проиндексирована; найдена, но не просканирована; Google выбрал другой канонический адрес;
  дубль; noindex; robots.txt; мягкая 404; 404; ошибка сервера; редирект; Google о странице не знает;
- Google выбрал не тот canonical, который указан на странице;
- страница закрыта robots.txt для Google.

### 11. Скорость по Google (`--psi`, 4 параметра)

Данные реальных посетителей Chrome (Core Web Vitals, по ним Google ранжирует) и лабораторный замер, телефон:
LCP (загрузка главного блока, хорошо до 2,5 с), INP (отклик на нажатие, до 200 мс), CLS (сдвиги вёрстки, до 0,1),
оценка PageSpeed из 100.

## Что не проверяется

- JavaScript не выполняется: программа видит HTML, который отдаёт сервер. Сайт, у которого текст появляется
  только после скриптов, проверьте ещё в Вебмастере и Search Console («Проверка URL»).
- Скорость меряется через Google PageSpeed, а не в своём браузере.
- Данные Вебмастера и Search Console – выборки API (до 100 событий, до `--gsc-inspect` страниц).
